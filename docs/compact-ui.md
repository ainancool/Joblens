# SG Job Lens 0.8.1 紧凑版

本版针对上一版“卡片过大、页面过长”的问题调整信息结构，而不是简单缩小字号。主页面先给摘要与操作，完整依据和长文本按需查看。

## 页面变化

| 页面 | 默认显示 | 按需查看 |
|---|---|---|
| 薪资 | 同公司公开报价 + 本公司/全市场两行统计；样本数与小样本警告保留 | 样本列表、原职位链接、完整统计 |
| 公司 | 三项招聘摘要 + 紧凑的评价入口 | 最近职位列表 |
| 机会 | 默认3个相似岗位；保留原薪资筛选 | 展开全部已获取岗位，外部网站搜索 |
| 求职AI | 简历状态、三项任务、AI去向与生成按钮，一个紧凑操作区 | 独立简历编辑、JD全文与完整提示词预览 |

顶部去掉重复标语和页面副标题。切换功能页保留各页自己的阅读位置，避免从长列表切到AI时仍停在底部。弹层可按Escape或点击关闭返回，统计详情关闭后恢复按钮焦点，简历草稿不会因关闭或切页丢失。

生成提示词会打开完整预览层，正文在限定区域内滚动，底部“复制/打开”固定可见。长提示词、简历和JD仍完整保留在原解析上限内，并非通过删减文本制造短页面。用户只有查看全文时才需滚动该文本区域。

## 同一样本的实测结果

测试使用400×600px视口、同一组虚构职位/MCF样本、默认关闭详情，测量侧栏内容区的 `scrollHeight` 与可见高度：

| 页面 | 0.8.0内容高度 / 可见高度 | 0.8.0额外滚动距离 | 0.8.1内容高度 / 可见高度 | 0.8.1额外滚动距离 |
|---|---:|---:|---:|---:|
| 薪资 | 974 / 382px | 592px | 453 / 453px | 0px |
| 求职AI | 857 / 382px | 475px | 453 / 453px | 0px |

紧凑版还通过320/400/600px宽度、600/720px高度、浅/深色和四页共48种组合的横向溢出检查；这些组合的默认薪资/AI摘要无需纵向滚动。准备好提示词、复制并关闭预览后，测试样本的AI主操作仍在首屏。

这是固定样本的测量，不承诺所有窗口和所有状态都永不滚动。特别长的职位名、错误提示、主动展开的列表、编辑与阅读长文本，以及明显低于600px的窗口仍可能需要滚动。

## 保留的功能与安全边界

10项随包数据回归通过；完整样本、机会展开、筛选、Escape焦点、简历草稿、存储失败、预览及复制均有浏览器验收。真实Chrome加载MV3扩展后，原内容采集、后台查询/缓存、侧栏渲染、保存简历、预览与刷新不删除简历的链路也通过。

核心算法、MCF查询、LinkedIn采集、文件解析、vendor及Chrome权限未改动。（0.9.0 起：点击发送会在新打开的 AI 对话中自动填入并发送，见 README。）没有新增后台、登录或自动投递。所有验收采用离线固定样本，没有调用真实MCF或向AI发送用户材料；未来外部API、网页DOM、AI预填行为仍受对方实现影响。

## 更新

解压新版，将文件更新到旧插件的原加载目录，在 `chrome://extensions` 点击“重新加载”，然后刷新LinkedIn职位页。不要先卸载旧扩展，以免Chrome删除已保存简历。保持原加载路径更有利于保留扩展ID与本机设置。
